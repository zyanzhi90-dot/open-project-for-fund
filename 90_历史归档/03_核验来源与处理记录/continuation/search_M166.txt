# 华中师范大学智能健康交叉科学中心2026年10月科研助理招聘公告

发布日期：2026年09月24日 09:04 作者： 点击：

//中心简介//

华中师范大学位于九省通衢的湖北省武汉市，是教育部直属重点综合性师范大学，国家“211工程”重点建设大学，国家教师教育“985优势学科创新平台”建设高校和“双一流”建设高校。

华中师范大学智能健康交叉科学中心瞄准智能健康领域器件与装备理论前沿和颠覆性技术，坚持以国家和湖北省的重大需求为牵引，以交叉科学研究带动核心技术体系突破，推动相关底层系统研发、顶层应用变革升级，推动学科交叉与人才培养的有机协调互动，促进国内外相关学术领域的交流合作，创造良好的交叉科学研究氛围。中心围绕“理论体系构建-系统集成方法-制造技术-重大应用”这一主线，构建“基础研究-技术攻关-产业转化-规模应用”全链条创新生态，对提升我校学科发展、构筑新工科育人平台、国家行业转型升级、多场景应用示范等发挥着至关重要的作用，为我国的“新工科”建设提供可复制、可推广的示范性经验。

//招聘计划//

科研助理1人。

//招聘条件//

一、岗位要求

1. 政治素质高，遵纪守法，品行端正，具有良好的职业道德素养；

2. 热爱教育事业，敬业精神和团队合作意识强；

3. 身心健康，能够适应岗位要求；

4. 专业基础扎实，具备岗位所需理论知识和业务能力。

5. 要求本科生及以上学历，包括但不限于化学、材料、环境、电子信息、计算机等相关专业。

6. 原则上不超过38周岁（1988年1月1日后出生），特别优秀者适当放宽。

二、岗位职责

1. 协助项目开展各项实验操作，参与数据的采集、整理、处理与分析工作。

2. 负责相关技术文档、研究报告及项目进展材料的撰写。

3. 完成负责人交办的其他科研相关工作。

//招聘程序//

1.应聘人员提交报名材料到邮箱：ihealth@ccnu.edu.cn，邮件主题为：“姓名+科研助理应聘”，附件简历应包括个人基本信息、联系方式、学习工作经历等，简历命名与邮件标题相同。报名截止时间为：2026年10月7日。

2.中心对报名材料开展初审，简历初审通过人员将受邀参加考核。名单及时间请及时关注中心官网通知（https://ihealth.ccnu.edu.cn/）。

3. 确定拟录用 人员名单，并在官网进行公示。

4. 政审，进行政治思想、师德师风审查。

5. 聘用签订合同，办理入职手续。

//岗位说明//

1. 用工形式：学校合同聘用制（C类）人员，以劳务派遣方式用工（编制外用工），一经录用，按照国家和学校相关规定签订劳务派遣合同、办理社会保险（“五险”+住房公积金）。

2. 薪资待遇：基本工资+岗位绩效+考核绩效。

3. 试用期一个月。

4. 报名人员所提供的材料和信息必须真实、准确，凡弄虚作假者，一经查实，一律取消资格。

长期招聘科研助理。

四、岗位职责

1. 协助科研教师做好科研相关的日常工作、以及课题组交办的其他科研辅助工作；

2. 负责科研实验室的日常运营维护；

3. 协助做好中心内部综合协调、会议组织、材料撰写等行政事务；

4. 完成中心领导交办的其他专项工作。

五、招聘程序

1. 应聘人员提交报名材料到邮箱：ihealth@ccnu.edu.cn，邮件主题为：“姓名+联系方式+应聘岗位”，附件材料应包括：（所有材料按顺序整理成一个PDF文档发送。）

（1）个人简历；

（2）身份证；

（3）学历学位证书及学历学位认证材料；

（4）外语水平证明材料；

（5）主要获奖证书等相关材料；

（6）任职证书、聘书等其他与岗位工作相关的职业资格证书等。

2. 中心审查应聘者材料，择优确定人员名单后组织面试，面试名单和时间请关注中心官网通知（https://ihealth.ccnu.edu.cn/），面试需携带证明材料原件。

3. 确定拟录用人员名单，并在官网进行公示。

4. 政审，进行政治思想、师德师风审查。

5. 聘用签订合同，办理入职手续。

六、岗位说明

1. 用工形式：学校合同聘用制（C类）人员，以劳务派遣方式用工（编制外用工），一经录用，按照国家和学校相关规定签订劳务派遣合同、办理社会保险（“五险”+住房公积金）；
