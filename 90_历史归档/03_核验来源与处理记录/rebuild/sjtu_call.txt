$.fn.smartFloat = function () {
            var position = function (element) {
                var top = element.position().top, pos = element.css("position");
                $(window).scroll(function () {
                    var scrolls = $(this).scrollTop();
                    if (scrolls > top) {
                        if (window.XMLHttpRequest) {
                            element.css({
                                position: "fixed",
                                top: 0
                            });
                            element.addClass("on");
                        } else {
                            element.css({
                                top: scrolls
                            });

                        }
                    } else {
                        element.css({
                            position: pos,
                            top: top
                        });
                        element.removeClass("on");
                    }
                });
            };
            return $(this).each(function () {
                position($(this));
            });
        };

上海市柔性医疗机器人重点实验室开放课题
时间：2026.07.20
为贯彻上海市重点实验室高水平合作交流的方针，创造良好的科研条件和学术氛围，吸引、凝聚优秀人才共同研究、联合攻关，促进高水平成果产出，现根据重点实验室建设相关要求面向国内外学者设置开放课题。
一、资助研究方向
以柔性医疗机器人为载体，以科学问题为导向，围绕实验室主攻方向支持开展具有原创性的基础研究与医工交叉研究，重点支持但不限于以下研究方向：
■ 连续体、仿生和软体机器人
■ 多相复合材料与超材料
■ 微纳机器人设计和制造
■ 微纳生物医学光电组件与植入
■ 机器人控制、感知和启发式学习
■ 生物光子学技术与疾病原位、活体组织特性表征
■ 脑机接口与康复及机器人与全程健康管理
二、资助项目类型
资助类别分为重点项目和一般项目。
三、申请人资格
3.1 项目第一负责人：具有高级职称或博士学历学位，在相关研究领域具有良好的前期研究基础。
3.2 重点项目第一负责人：原则上具有博士研究生导师资格。可依托重点实验室招聘博士后，开展该课题工作。
3.3 申请人应为实验室的课题组或合作课题组的研究人员、临床人员。可独立申报，也可医工交叉联合申报。
3.4 实验室开放课题采用滚动支持方式，结题优秀者，可优先申请下一周期资助。
四、申报指南咨询方式
有意向申报者，可发送个人基本信息、联系方式、学习和工作经历、主要学术成就至实验室联系人邮箱，邮件主题为：姓名-单位-市重点实验室开放课题咨询。
五、联系方式
电话：18917129802（徐老师）
