## 自动上传

后续项目工作遵循 AGENTS.md，每次完成修改后运行 `scripts/sync-github.ps1`，自动提交并推送到本仓库 main 分支；没有文件变化时不生成新提交。另由 Codex 定时检查补充同步，需本机 Codex 可运行且网络可用。

手动同步：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\sync-github.ps1
```

依赖、缓存、Excel临时文件和个人未公开面上申请书不上传。远程有未合入变更时停止同步并报告，避免覆盖远程内容。
